# English CLOSED-CLASS function words, used as the COUNTERWEIGHT to swedish-function-words.txt.
#
# WHY a second list. A one-sided Swedish test cannot tell "this row is Swedish" from "this row is English
# that happens to contain a shared token". Scoring both sides and requiring Swedish to WIN is what makes
# the detector safe to purge on. It also handles the mixed rows, where an English sentence quotes a
# Swedish identifier: those score high on both, so they are not confidently Swedish and are left alone.
#
# Same precision-first rule as the Swedish list: a word that is also a common Swedish word, or a likely
# Scala token, does not belong here. Excluded for exactly that reason: "for" (Scala keyword), "do",
# "then", "case", "new", "this", "val", "if", "else", "while", "try", "match", "type", "object", "class",
# "import", "return", "true", "false", "null", "end" — all Scala keywords that would fire on any code
# listing and wrongly pull a Swedish row toward English.
#
# Format: one word per line, lowercase. `#` starts a comment. Blank lines ignored.
