# English mode half Swedish.

# the next successful single pass embedded only 127 bookmarks instead of 982. The map fell to 115
# pairs, FindHeadings still printed OK! in green, and the collapsed table was committed into
# muntabot. Re-running `sbt pdf` restored 982 bookmarks and 778 pairs.
