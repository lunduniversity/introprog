# Headings whose English is CORRECTLY identical to the Swedish.
#
# `sbt gen` counts headings whose English equals their Swedish. Most such matches are not
# defects at all -- proper nouns, git terms, tool names -- so a raw count is dominated by
# them and stops being worth reading. Everything listed here is a DECISION that the two
# sides should stay the same; anything NOT listed is reported as untranslated Swedish that
# somebody still has to rule on.
#
# That is the whole point: keeping a heading Swedish is a recorded choice, never a silence.
#
# When gen reports a heading here, do ONE of:
#   1. translate it yourself      -> add an entry to autotranslate/Overrides.scala
#   2. hand it to an assistant    -> same sink, an Overrides entry, still reviewed by you
#   3. let the local model try    -> `sbt "autotranslateProject/run --all"` with a backend,
#                                    then review what it produced
#   4. keep it Swedish on purpose -> add the exact Swedish heading to THIS file, with a why
#
# One heading per line, exactly as it appears in the generated map. `#` starts a comment.
