Instruktioner

I denna kurs använder vi programmeringsspråket Scala med olika programmeringsverktyg.
Läs om hur du använder verktygen i Appendix i kompendiet.

Verktygen finns förinstallerade på LTH:s Linuxdatorer i E-huset, se även Programmera på LTH:s datorer.

Tips om köp av egen dator finns under Hårdvara.

Programmera på din egen dator

Du behöver installera:

  • OpenJDK 25
  • Scala 3
  • VS Code med tillägget Scala (Metals)
  • Git

Följ instruktionerna noga under rubriken för ditt operativsystem.

Välj operativsystem/metod

  • Windows
  • macOS
  • Linux (Ubuntu)
  • WSL
  • Dual booting
  • SDKMAN (Linux/macOS/WSL)
  • Hårdvara

Om problem uppstår kan du få installationshjälp under kursens första två veckor på luncherna i E:2116.

Windows

Innan du börjar:

  • Kontrollera om datorn är x86 eller ARM (vanligast är x86):
    Settings → System → About
    Microsoft-guide
  • Slå på visning av filändelser och dolda filer i Utforskaren: Microsoft-guide

1) Terminal

  • Rekommenderat: Windows Terminal (standard i Windows 11).
    Installationsguide: learn.microsoft.com
  • Kommandoreferenser:
    • CMD: https://ss64.com/nt/
    • PowerShell: https://ss64.com/ps/
  • Om du föredrar Unix-lik terminal: använd Git Bash (installeras med Git).

2) Installera OpenJDK 25

Kontrollera först:

javac --version
  • Om javac saknas eller versionen är äldre än 25: installera OpenJDK.
  • Om du har en äldre JDK: avinstallera den först.

Installera från: https://adoptium.net/

  1. Välj Download Temurin.
  2. Kör installationsfilen.
  3. Välj Install Entire Feature för:
    • Modify PATH variable
    • Associate .jar
    • Set or override JAVA_HOME variable
    • JavaSoft (Oracle) registry keys
  4. Starta om datorn.
  5. Verifiera igen: 
    javac --version

3) Installera Scala

  1. Välj metod beroende på arkitektur.

x86:
Ladda ner: cs-x86_64-pc-win32.zip
Packa upp och kör installationsfilen.

ARM (PowerShell/Windows Terminal):

Start-BitsTransfer -Source https://github.com/coursier/launchers/raw/master/coursier -Destination coursier
Start-BitsTransfer -Source https://github.com/coursier/launchers/raw/master/coursier.bat -Destination coursier.bat
.\coursier setup

ARM (endast CMD):

bitsadmin /transfer downloadCoursierCli https://github.com/coursier/launchers/raw/master/coursier "%cd%\coursier"
bitsadmin /transfer downloadCoursierBat https://github.com/coursier/launchers/raw/master/coursier.bat "%cd%\coursier.bat"
.\coursier setup
  1. Starta om datorn.
  2. Kontrollera: 
    scala --version
    Du ska få något som börjar med Scala code runner version 3.

Om du får varning med MainGenericRunner, installera explicit version:

cs install scala:3.7.4

4) Installera VS Code + Scala (Metals)

  1. Installera VS Code: https://code.visualstudio.com/Download
  2. Installera tillägget Scala (Metals) via Extensions, eller: 
    code --install-extension scalameta.metals --force
  3. Första gången kan indexering ta tid. Klart när status visar Index complete.
  4. Vid problem: stäng VS Code och ta bort ev. kataloger: .bsp, .bloop, .vscode, .metals, .scala-build, target.

5) Installera Kojo

  1. Ladda ner: https://fileadmin.cs.lth.se/kojo.scala
  2. Öppna mappen i VS Code och kör: 
    scala repl .

6) Installera Git

  1. Ladda ner: https://git-scm.com/download/win
  2. Följ standardvalen (editor: gärna nano).
  3. Verifiera: 
    git --version

macOS

Innan du börjar:

  1. Kontrollera arkitektur: 
    uname -m
  2. Slå på visning av filändelser och dolda filer: 
    defaults write NSGlobalDomain AppleShowAllExtensions -bool true && killall Finder
defaults write com.apple.finder AppleShowAllFiles YES && killall Finder

1) Terminal

Guide: How-To Geek

macOS använder ofta zsh som standard. Det fungerar bra. Bash är valfritt.

2) Installera Homebrew

/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

Verifiera:

brew --version

Valfritt: iTerm2 + Bash

brew install --cask iterm2
brew install bash

Byt standardskal (Apple Silicon-exempel):

chsh -s /opt/homebrew/bin/bash

3) Installera OpenJDK 25

Kontrollera först:

javac --version

Om javac saknas eller version < 25:

brew install openjdk@25

Lägg till i miljön (Apple Silicon-standard):

echo 'export PATH="/opt/homebrew/opt/openjdk@25/bin:$PATH"' >> ~/.bash_profile
echo 'export JAVA_HOME=$(/usr/libexec/java_home -v 25)' >> ~/.bash_profile
source ~/.bash_profile

Verifiera:

javac --version

4) Installera Scala och Scala CLI

brew install scala
brew install Virtuslab/scala-cli/scala-cli
scala --version

5) Installera VS Code + Scala (Metals)

  1. Ladda ner: https://code.visualstudio.com/Download eller: 
    brew install --cask visual-studio-code
  2. Installera Metals: 
    code --install-extension scalameta.metals --force
  3. Vänta tills Index complete.
  4. Vid problem, rensa .bsp, .bloop, .vscode, .metals, .scala-build, target.

6) Installera Kojo

  1. Ladda ner: https://fileadmin.cs.lth.se/kojo.scala
  2. Öppna mappen i VS Code och kör: 
    scala repl .

7) Installera Git

brew install git
git --version

Linux (Ubuntu)

Innan du börjar:

  1. Kontrollera arkitektur: 
    uname -m
  2. Slå på visning av dolda filer och filtyp: 
    gsettings set org.gtk.gtk4.Settings.FileChooser show-hidden true
gsettings set org.gtk.gtk4.Settings.FileChooser show-type-column true

1) Öppna terminal

Ctrl + Alt + T

2) Installera OpenJDK 25

Kontroll:

javac --version

Om fel version/saknas:

sudo apt update && sudo apt full-upgrade -y
sudo apt install openjdk-25-jdk openjdk-25-doc openjdk-25-source

Verifiera:

javac --version

3) Installera Scala-verktyg

Kontrollera curl:

curl --version

Installera vid behov:

sudo apt install curl

Installera med Coursier:

x86:

curl -fL https://github.com/coursier/coursier/releases/latest/download/cs-x86_64-pc-linux.gz | gzip -d > cs && chmod +x cs && ./cs setup

ARM64:

curl -fL https://github.com/VirtusLab/coursier-m1/releases/latest/download/cs-aarch64-pc-linux.gz | gzip -d > cs && chmod +x cs && ./cs setup

Svara Y om du blir tillfrågad om PATH. Starta om datorn och kontrollera:

scala --version

Vid MainGenericRunner-varning:

cs install scala:3.7.4

  3. Vänta tills Index complete.
  4. Vid problem, rensa .bsp, .bloop, .vscode, .metals, .scala-build, target.

5) Installera Kojo

  1. Ladda ner: https://fileadmin.cs.lth.se/kojo.scala

WSL

WSL2 rekommenderas om du vill ha Linuxmiljö men behålla Windows.

  1. Öppna Windows Terminal som administratör och följ: docs.microsoft.com/windows/wsl/install
  2. När Ubuntu är installerat, följ avsnittet Linux (Ubuntu).
  3. Installera VS Code i Windows + tillägget Remote - WSL: VS Code WSL-guide
  4. Ljud i WSL2 (vid behov): sound_in_wsl2.md

Dual booting

  • Ersätta Windows med Ubuntu: ubuntu.com/tutorials/install-ubuntu-desktop
  • Köra dual boot: Guide på Medium

SDKMAN

För Linux/macOS/WSL kan du använda SDKMAN för versionshantering.

Installera (efter att SDKMAN installerats enligt deras guide):

sdk update
sdk install java 25
sdk install scala
sdk install scalacli
sdk install sbt

Svara Y om du får fråga om att sätta version som default.

Tips: Blanda inte installationsmetoder i onödan (brew/apt/sdkman/coursier), det försvårar uppdatering och felsökning.

Hårdvara

Vid undervisning på campus rekommenderas LTH:s Linux-datorer.

Hemma rekommenderas en bra arbetsplats samt dator med Linux, Windows eller macOS.

Köpa egen dator

För programmering rekommenderas minst:

  • 16 GB RAM
  • modern fler-kärnig CPU (t.ex. Ryzen eller Intel Core i5/i7)

Lenovo ThinkPad nämns ofta som robust alternativ. Begagnat kan vara prisvärt:

  • Inrego (t.ex. ThinkPad T14)
  • Inet Refurbished
  • BilligTeknik

Nya datorer med studentrabatt:

  • Lenovo studentrabatt
  • Dell studentrabatt

Lokala butiker:

  • Inet Malmö
  • Webhallen Malmö
  • Compliq Lund

Fläktlös/tyst stationär dator:

  • AtLast Solutions
